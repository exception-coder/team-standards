# 显式批量注释清理

仅在用户要求批量清理时加载。规则复用 [comments.md](comments.md)，不扩展到业务逻辑、公共 API 或无关文件。

1. 确认本次文件范围，按目标语言解析注释与字符串，逐条理解再保留、压缩或删除；不能正则全删。
2. 保留许可证、工具指令、生成标记、编译/构建标签、lint 指令、必要 API 文档及有效业务解释。字符串内 SQL/示例文本不能按宿主注释误删。
3. 删除历史叙事、重复代码含义、失效注释及确认无用的注释代码；非显然约束用简洁原因说明，不强迫所有语言采用 Java 注释位置。
4. 审阅 diff，确认行为、字符串、指令和编码未变；执行适用格式/构建或相关检查。发现逻辑缺陷另行按已授权范围处理，不夹带修复。
5. 按提交规范交付；不自动生成日报或独立清理报告。
