# 提交格式、Hook 与版本细则

共同准则见[工程宪法](../../change-readiness/references/engineering-principles.md)；原子性、暂存保护、提交授权与推送边界由[提交主入口](../SKILL.md)维护。本文件只补格式、执行合同和版本规则。

## 提交信息格式

```text
<type>(<scope>): <标题>

【改动】<关键业务规则或技术处理怎样改变>
【原因】<原来在什么条件下出现什么问题，为什么>
【结果】<改后行为、已验证范围及仍待验证处>

Author: <姓名> <邮箱>
```

- type 使用 `feat/fix/refactor/perf/docs/test/style/chore/ci/revert`，scope 可选；按主要变更意图选择，不能以单一 type 掩盖独立问题。
- 标题不超过 72 字符，不加句号；三段中文正文顺序固定，小改也保留。
- Author 读取当前仓库 `git config user.name` 与 `git config user.email` 的实际有效值；缺失时只暂停提交，不编造身份。
- Author 后不追加 AI 署名、Generated by 或 Co-Authored-By。脚本检查结构与作者，不证明内容准确或提交原子性。

## 写给未来读者的提交说明

读者应能串起“原来怎样 → 为什么 → 关键环节怎样改 → 现在怎样”。正文以会话事实、staged diff 和有效证据为依据；文件、版本与测试数仅作定位补充。

| 段落 | 要解释的内容 |
|---|---|
| 改动 | 哪个业务或技术环节用了什么规则，怎样处理原问题 |
| 原因 | 什么条件下出现什么问题，已证实原因和推断如何区分 |
| 结果 | 行为怎样变化，已验证哪些边界，哪些尚待验证 |

技术名词帮助精确定位，不能代替因果解释。消息长度随复杂度，避免逐文件翻译 diff、空泛收益或未证实的性能承诺。

## 消息生成与提交

在作者、范围、文档及验证已核实后使用：

```bash
node "<skill-dir>/scripts/build-commit-message.js" --repo "<repo>" --title "type(scope): 标题" --change "具体改动" --reason "原因" --result "实际结果"
git commit -F "<脚本输出的绝对路径>"
```

`<skill-dir>` 是主 SKILL.md 所在目录。脚本不猜业务意图；兼容 `--body` 仅接收已组装的三段正文。正常自动提交不额外要求用户审阅正文；用户明确要求查看或缺少必要确认时，再展示具体消息。

失败保留现场并报告，不绕过 Hook。宿主未执行 Hook 不代表已校验，小改豁免不改变消息合同。

## 插件与 MCP 版本规则

- 插件运行载荷 `skills/`、运行时 `hooks/`、`commands/`、`agents/`、`apps/`、`mcp/` 变化时升插件版本；只有 README、docs、测试、benchmark 或纯发布脚本变化不触发。
- team-standards 的 marketplace、Claude plugin 与 Codex plugin 三处 manifest 同步；修改 CLAUDE.md 后运行 `node scripts/sync-agents.js` 生成 AGENTS.md，并执行仓库要求的检查。业务项目不套用插件升版规则。
- MCP 引擎的源码、工具 schema、依赖锁或构建合同变化时升 package.json 并同步 server info；只有知识 Markdown 变化不升引擎版本，按已采用协议刷新 catalog 与 reload_knowledge。
- 推送按主入口授权边界。版本递增不代表安装缓存、运行会话或业务系统已升级。

## 精炼反例

| 做法 | 判断 |
|---|---|
| “新增类、更新 README、升版本”写满三段 | 补清触发问题、关键处理和行为结果 |
| 部分提交借用整个工作区的 PASS | 核对待提交快照与依赖 |
| 默认本地 commit 就推送业务项目 | push 单独核对已有授权 |
| 生成器通过就认为提交质量合格 | 还要审读语义、范围和验证依据 |

## 示例

以下是写法示意，实际提交必须替换为当前证据：

```text
fix(order): 避免取消重试重复释放库存

【改动】仅释放仍被当前订单占用的库存，同一取消请求再次到达时返回已有处理结果。
【原因】原流程重试取消时再次增加可售库存，可能让库存数量超过实际可用量。
【结果】取消重试不会重复释放。已验证正常取消及重复请求，跨系统联调尚未完成。

Author: <当前 Git 配置中的真实姓名> <真实邮箱>
```
