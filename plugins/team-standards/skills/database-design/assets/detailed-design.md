# 库表详细设计

按[共用格式](../../change-readiness/references/engineering-design-output.md#共用格式与事实口径)交付独立方案，或放入既有详设。只展开本期受影响的结构、读写和迁移。

开头引用覆盖本期的全景图，或按需补一张。物理 ER 和迁移图用于解释全景图未展开的关系或切换顺序。

## 物理结构与关系

注明数据库引擎、版本/方言、目标环境和基线来源。逐表写物理名、业务用途、归属及主键策略。

| 字段 | 类型及长度/精度 | 可空 | 默认值 | 业务含义 | 值域、单位或规则 |
|---|---|---|---|---|---|
| 〈字段名〉 | 〈目标方言〉 | 〈是/否〉 | 〈默认值〉 | 〈业务语义〉 | 〈枚举、状态变化或限制〉 |

注明主键、唯一、外键、检查约束及实际落点。写清关系基数、关联字段和删除策略，必要时附物理 ER 图。

## 访问与索引

| 访问场景或 SQL 位置 | 过滤、关联、排序与分页 | 索引和列顺序 | 依据及验证 |
|---|---|---|---|
| 〈查询、写入或批量场景〉 | 〈条件及结果语义〉 | 〈已有、拟新增或无需索引〉 | 〈数据规模、并发、计划、写入成本〉 |

按需补目标方言的核心 SQL 及事务相关约束，注明 SQL 的验证环境和结果。

## 结构演进与迁移

列出前置条件、DDL/DML、依赖顺序、新旧版本兼容窗口、回填及验证。存在中断或不可逆步骤时，写停止条件、恢复或前滚路径及责任边界。

## 验收与证据

为受影响的结构、约束、核心 SQL 和迁移分别写验证条件、预期结果、验证工具及证据位置。历史空值或重复、并发冲突、兼容窗口及迁移中断按实际风险选择。
