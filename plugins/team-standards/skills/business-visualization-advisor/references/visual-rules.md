# 图表选择规则

## 1. 从分析任务到表达方式

以下是默认偏好，业务任务与数据证据优先；类别数和点数阈值是可调整启发式。

| 分析任务 | 优先表达 | 条件与降级 |
|---|---|---|
| 一个重要量、比例或目标差距 | KPI、带目标的条形 | 同时说明单位、期间、分母；无目标依据不用仪表盘 |
| 状态数量、类别比较、排名 | 条形图，长名称用横向 | 按业务顺序或数值排序；高基数使用 Top N 与可探索明细 |
| 同一总体的构成 | 条形、100% 堆叠条；少量类别可用环图 | 类别互斥、总体完整、数值非负；环图默认不超过 4 类，接近值需精确比较时用条形 |
| 连续期间的变化 | 折线或期间柱形 | 有真实时间序列、明确时间粒度；默认少于 3 个有效点改用差值摘要或事件列表 |
| 稀疏业务事件 | 事件列表、时间点标记 | 不把两次事件连成连续走势；聚合粒度合理时才转期间计数图 |
| 超期、待处理、异常 | 告警摘要与行动明细 | 用状态与责任人定位处理；历史充分时才增加带注释趋势 |
| 流程瓶颈 | 各状态积压条形、停留时长分布 | 当前状态支持积压，时长需要可靠进入时间；不要根据状态数量差宣称转化流失 |
| 阶段转化 | 漏斗或阶段转化表 | 相同队列、明确阶段顺序和观察窗口、去重和回退规则；快照各状态数量不是漏斗 |
| 数量/金额/时长分布 | 直方图、箱线图 | 明确粒度、单位、分箱与样本量；小样本改用点图/表格，不暗示稳定分布 |
| 两个量的关系 | 散点图 | 同一对象粒度配对、样本足够；标明相关不代表因果 |
| 精确查值、多维明细 | 表格 | 保留排序筛选，数值对齐；不能因为“看板”就禁止表格 |
| 数据不足或无决策收益 | 文本摘要、空状态、不放图 | 不补造历史、不用无意义图占位 |

## 2. 防止误读

- 条形长度比较通常从零起点；非零折线轴明确刻度和范围。不使用 3D、无意义双轴或面积夸大差异。
- 缺失时间桶只有确定“采集完整且确实无事件”才补零；缺数留空或标记，不能插值伪造事实。未结束期间与完整期间不可直接比较，采用同进度窗口或显式提示。
- 环比/同比零基期不显示无穷增长；比例差标百分点，与相对变化率分开。各分组比例不能直接平均替代总比例。
- Top N 展示须说明全量范围，“其他”可展开且不吞掉需要行动的关键异常；缺失归属不藏入“其他”。
- 生命周期状态可互斥，风险标签往往重叠；重叠标签不画份额图、不相加作总数。
- 没有 SLA、目标、基线或业务判定依据，不自动把最大值标红或生成“异常”结论。

## 3. 场景自检

- 60 件有效样衣中 56 件未归属：若聚合范围与权限一致，可说“56/60，93.3% 未归属”，用横条与明细；是否告警取决于归属规则。不能直接沿用示例中的 93% 为真实数据。
- 只有当前状态与创建时间：可展示当前状态分布、按创建时间统计的新增量；不能展示历史在库量、借出趋势或状态停留时间。
- 两个借用事件：优先事件列表；不得补造 30 天借出趋势。若有完整事件采集及明确窗口，可以按真实期间聚合，但要核实零桶含义。
- 借用截止已过但已归还、取消或豁免：不能计入当前超期；同一样衣多次借用按业务实例核实。
- 状态快照有待审核、进行中、完成：可以比较积压，不把三组数当转化漏斗。
- 没有数据权限或接口失败：显示对应状态，不能以“0 异常、一切正常”替代。
