# Visual Evaluation Rubric

Score applicable dimensions from 0 to 3 and cite evidence: `0` blocked, `1` material drift, `2` acceptable with minor drift, `3` aligned.

| Dimension | Review question |
|---|---|
| Hierarchy | Is importance legible without decorative containers? |
| Alignment | Do edges, grids, and control relationships feel intentional? |
| Spacing | Does spacing follow known tokens or observed rhythm? |
| Typography | Are roles, scale, weight, and line length coherent? |
| Density | Does density fit the task and profile? |
| Consistency | Are repeated components and states consistent? |
| Readability | Can users scan and understand content quickly? |
| Restraint | Does every effect serve hierarchy, interaction, or context? |
| Interaction | Are affordances, focus, feedback, and keyboard behavior clear? |
| Recovery | Do non-happy states provide a useful next action? |
| Responsive behavior | Does hierarchy reflow without overflow or desktop shrinkage? |
| AI-pattern risk | Are generic cards, pills, gradients, centering, and oversized icons grounded? |
| Token integrity | Are colors, spacing, radii, shadows, and breakpoints known? |
| Component reuse | Are duplicate components or local variants avoided? |

Record viewport, state, reference IDs, blockers, and dimensions not inspected. Never infer visual approval from a successful build.
