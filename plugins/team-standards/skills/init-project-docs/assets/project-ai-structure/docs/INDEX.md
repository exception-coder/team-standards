# {{PROJECT_NAME}} 文档索引

从这里链接项目现有的业务规则、设计、操作与验证说明。同一主题只维护一份正文；已有 README 或模块索引时优先链接原入口。

初始化时复用已有业务资料，从关键代码补齐主要能力、主流程与规则，保留依据并把推断标为待确认。无既有概览时先用 `docs/domain/overview.md` 合并表达，不生成五件套或空目录；项目已有其他归属时沿用。

索引应链接实际维护的业务概览和一张 draw.io 全景图；图的同源预览嵌入概览。图件沿用现有位置，无约定时用 `docs/diagrams/`。业务语义变化时同步受影响正文、源图与预览；空仓没有业务证据时明确说明缺口，不链接占位产物。

源码通过定向搜索、LSP（可用时）和 Git 理解；Graphify 与 OpenSpec 按项目采用情况使用，不是初始化前置条件。检索索引可重建，不另存知识正文。
