# 技术方案模板入口

技术 / 架构主导的方案统一使用[技术实现概设模板](../technical-implementation-design/assets/conceptual-design.md)和[详设模板](../technical-implementation-design/assets/detailed-design.md)。本入口保留已有引用，不再复制一套章节和绘图规则。

先用结论与 draw.io 全景图讲清边界、职责和关键路径；详设展开实现节点、契约、数据、事务、失败和验证。深度按[工程设计输出规则](references/engineering-design-output.md)选择，项目既有目录、编号和同文件绑定保持有效。

业务流程主导用[业务方案提纲](template.md)，单项局部决策用[轻量提纲](lightweight-template.md)。过会讲解用[过会模板](../clear-design-docs/assets/meeting-brief.md)，接入方操作用[Quickstart](../markdown-writing-standards/assets/quickstart.md)。
