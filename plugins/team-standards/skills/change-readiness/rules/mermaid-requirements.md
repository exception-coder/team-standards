# 设计图表的按需规则

[change-readiness](../SKILL.md) 的图表用于解释复杂关系，不是完成门槛。能用短文或表格清楚说明时不画图；各模板不设固定图数，不写“不适用”空章节。

| 问题 | 可选图 |
|---|---|
| 模块边界、依赖与数据所有权 | 架构或依赖图 |
| 分支、异常和业务路径 | 流程图 |
| 并发、事务、异步恢复与调用顺序 | 时序图 |
| 状态转换和禁止路径 | 状态图 |

只画受影响范围。同一事实不重复画多图；一张图混入不同问题且难以阅读时再拆分。图中关系须有证据，当前代码拓扑优先引用新鲜 Graphify，不手抄整套调用图。

存在多个职责域时用 subgraph、box 或 namespace 分组；单一短流程不强制套框。标题和节点用可读名称，标注箭头含义，避免超过两层嵌套。

生成 Mermaid 前读取 [Markdown 格式细则](../../markdown-writing-standards/references/markdown-format.md)，检查语法、链接和真实含义。未实际渲染时不声称视觉验证通过。
