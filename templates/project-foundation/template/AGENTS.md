# 项目开发约定

## 基础约定

本项目采用仓库内的基础规则，不要求开发者预装外部套件。个人或插件的同类基础建议与下列约定不一致时，按本项目明确选择的规则执行；用户明确要求和更高优先级约束仍须遵守。项目已有强制 CI、权限、兼容和数据规则不能因模板简化而跳过。

- 修改前确认目标、相关入口和已有改动；在已有授权内连续完成任务，只对阻塞当前操作的关键歧义补充信息。
- 采用满足当前目标的最小充分实现，保持职责清楚、依赖单向；复用已有能力，不为目录、层数或文件数量造空抽象。
- 新增业务类、模块和对外复用组件时补充职责与边界说明；新增或改变公共 API 时补调用契约；字段补单位、状态等非显然含义，复杂规则解释原因。代码改动必须同时核对注释的缺失与失效，不等用户提醒。
- 注释默认使用团队中文；项目明确要求其他语言时服从项目。使用语言原生文档注释；简单私有访问器和生成代码不机械补注释。
- 错误不能静默，外部输入须校验，资源须释放，凭据与敏感载荷不能写进源码或日志；修改文件保持原编码及项目格式。
- 优先使用项目已有测试、构建和检查，按实际影响选择范围；未运行、跳过、环境不可用与失败分别说明，不能冒称通过或已上线。
- 同次更新受影响的使用说明与契约，不为每次改动新增报告。提交只包含本次可分离逻辑单元，保留他人未提交和已暂存的内容。
- 默认在逻辑单元完成且验证通过后创建本地提交；用户或项目要求人工提交时遵守。推送、发布、部署和外部写入按各自授权执行，不因采用模板自动获得权限。

## 本地 Skill 路由

按任务读取以下文件；同一作业可复用已经读取且仍适用的规则。没有自动出现在宿主技能列表中时，按相对路径读取，不因无法发现插件而跳过规范。

| 当前任务 | 采用的本地入口 |
|---|---|
| 编写、修改或评审源码 | [基础编码](.agents/skills/foundation-coding/SKILL.md) |
| 新增或修改源码，包括未写注释的新增代码 | [代码注释](.agents/skills/foundation-comments/SKILL.md) |
| 调查异常或修复 Bug | [Bug 处理](.agents/skills/foundation-bugfix/SKILL.md) |
| 可执行改动完成，准备交付 | [验证](.agents/skills/foundation-verification/SKILL.md) |
| 准备提交或编写提交说明 | [Git](.agents/skills/foundation-git/SKILL.md) |
| 更新功能说明，创建或修改文档 | [文档](.agents/skills/foundation-docs/SKILL.md) |

六类基础任务优先使用以上项目内版本，不同时套用外部同类 Skill 的另一套模板或流程。专项能力按任务和项目实际接入情况选用；外部 Skill 的选择不会关闭已注册的 Hook，发现互相矛盾的检查时核对真实配置，不绕过项目强制要求。

## 项目特有约定

项目维护者在此补充真实的架构边界、技术栈、构建测试命令、兼容要求和明确例外。接入既有项目时合并原有规则，不能覆盖或删除原有正文。没有声明的命令由 Agent 检查实际脚本和构建配置后选择，不假定模板已配置检查工具。
