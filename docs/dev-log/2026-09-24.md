# 2026-09-24 套件开发记录

## Yoooni One 前端纠错历史沉淀

**原因：** 前端通用规则已覆盖反模板化、响应式和浏览器验收，但缺少可追溯的业务 UI 纠错案例和可复用 Eval。Yoooni One 的移动检索、样衣卡片、滚动、概览、状态、权限与登录页存在多轮具体修正。

**决策：** 在现有 `frontend-excellence` 和 `business-visualization-advisor` 中补充 Page Anatomy、比较任务驱动密度、移动首屏、滚动归属、状态与操作色分工、分层解释和 NO CHART；建立一份带提交号、前后证据、Review 与 Eval 的参考。静态扫描只列候选，先测误报与宿主覆盖，不宣称已实现阻断 Gate。

**影响：** 套件规则与参考升版 4.8.1，未改 Yoooni One。现有 Skill 触发边界保持不变；项目特殊尺寸、品牌和状态含义继续由项目维护。
