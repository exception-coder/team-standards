# 开发日志 · 2026-08-13

## 22:50 · 修复规则 · git-commit-standards 提交正文闭环

**原因：** 2026-08-04 已决定所有提交都要主动生成正文，但主入口和 Skill description 仍保留“大改或用户显式提交才触发”的旧路由，导致小改与自动收尾偶发绕过；同时现有机械门禁只验证任意中文正文，无法保证说明代码做了什么、为什么做以及解决了什么。

**改动：**

- 将 `git-commit-standards` 的触发边界统一为任何提交前必走，改动大小只控制是否追加五步重审
- 将提交正文固定为 `【改动】`、`【原因】`、`【结果】` 三段式契约
- 让消息生成器和 Hook 复用同一校验器，并增加缺段回归测试

**影响：**

- 小改、自动收尾和未显式要求 commit 的提交也必须主动生成完整正文
- 后续提交历史稳定保留代码动作、决策依据与问题闭环
- Bash Hook 仍是机械兜底；不提供该 Hook 的宿主依靠 Skill 主动生成保证完整性
