# 开发日志 · 2026-08-02

## 22:58 · 修改配置 · Git 提交信息结构门禁

**原因：** Skill 虽然要求提交正文和真实 Author，但现有 Hook 只拦截 AI 署名，标题式提交仍能落盘，导致后续人工与 AI 无法从 Git 历史回归改动原因和影响范围。

**改动：**
- 将提交 Hook 扩展为标题、中文正文和 Author 的结构校验
- 保留 AI 署名拦截，并兼容原有环境变量
- 增加内联消息、文件消息、缺项和 warn 模式测试

**影响：**
- 后续 AI 发起的非交互式提交缺少正文或 Author 时会被直接阻断
- 团队提交历史将稳定保留改动内容、原因与影响范围
- 小改只跳过重型检查流程，不再豁免完整提交消息格式
