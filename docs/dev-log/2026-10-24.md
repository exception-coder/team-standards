## 第四轮：Linux 符号链接回归（4.14.4）

- Windows 与 Linux 的四项定向回归全部通过，包括外部链接拒绝、显式输入拒绝、正常净差异与仓内链接。

## 跨仓 CI 检出与发布预检修复

`cross-project-topology` 的 GitHub 仓库为私有仓库，当前工作流的默认令牌不能跨仓读取。按用户选择改用 Actions Secret `TEAM_TOOLS_READ_TOKEN`，默认工作流权限限制为 Contents 只读，私有 checkout 不持久保存凭据；未配置 Secret 时立即给出明确错误。

对照五个仓库的当前远端提交执行完整隔离演练后，补齐此前被检出失败遮住的两个问题：全新 Runner 缺少发布预检需要的根 README，因此仅在临时工作区生成组件总览；发布脚本仍调用日常插件已经删除的 onboard 测试，移除过期调用，该能力仍由 team-standards 的全量测试覆盖。
