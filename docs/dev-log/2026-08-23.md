# 开发日志 · 2026-08-23

## 10:42 · 新增 Skill · planning-evidence-discovery

**原因：** 现有规划链按单个项目固定查询领域知识、Graphify、DDL 和路由，无法消费重构、迁移、依赖与集成关系；即使关联项目证据真实存在，也可能被错误描述为缺失。单纯扩充提示词无法证明工具已经执行，也无法支撑后台恢复和完成性门禁。

**改动：**
- 新增跨项目规划证据探索 Skill，强制先由 Forge 解析项目范围，再由 Agent 按关系动态选择证据源。
- 定义项目关系、项目角色、统一证据查询和 `planning-evidence-trace-v2` 机器契约。
- 明确真实工具调用是轨迹唯一来源，服务端最多驱动三轮补查。
- 保留 Graphify、领域知识 MCP 和 cross-project-locator 的单一职责，把它们作为证据适配器而非项目关系权威源。

**影响：**
- PRD 初始化规格、价值分析和工时评估需要复用同一份持久化证据轨迹。
- Forge 需要实现 scope resolver、统一查询适配、轨迹持久化、后台恢复和完成性门禁后，才能形成完整闭环。
- 插件升级到 1.56.0，团队成员更新后可获得新的探索规则与平台接口契约。
