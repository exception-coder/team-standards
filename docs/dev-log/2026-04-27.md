**改动：**
- `skills/korepos-backend-service/SKILL.md`「BackendInfra 门面规则」节新增「情况 C — 新实现的「backend 内部基础设施」（云端通信 / WS 推送 / 设备协议等）」子节：
  - 解释「为什么不能挂到 BackendInfra」（旧实现防腐过渡门面定位）
  - 给出「判断是不是新实现」的 1 个问句（是否从 0 按 backend 蓝本写，而非包装 application/data/domain/presentation 旧 service）

  - 给出 Service 平级注入的代码范本（`_infra.xxx` 旧实现 vs `_{capability}.xxx` 新实现）
  - 列出 3 条红线（不留 BackendInfra 转发 getter / 子门面 client 不反向依赖 BackendInfra / 新 DTO 不放业务模块目录下）
