# 2026-09-13 开发决策日志

## 01:40 — 工作台可用视口验收

**原因**：用户在 Forge Agent 管理页再次指出底部可见空间未被工作区利用。页面外层满高不足以保证中间容器与左右面板继承剩余高度，原有响应式验收主要检查宽度与溢出。

**改动**：在 frontend-excellence 的既有质量门禁中定义工作台可用视口契约，主 Skill 和视觉检查表引用同一正文；同步入口及中英文说明，版本升至 3.4.1。要求真实浏览器覆盖高屏、矮屏、窄屏、动态 resize、长短内容与操作可达性。

**影响**：适用于操作型工作台；阅读页和短表单可保持自然内容高度及局部限宽。没有新增 Hook、检查器或全屏强制样式；未测试的宿主形态必须披露，不能以截图宽度或编译成功宣称响应式完成。

## Go 语言规范与 DDD-lite 接入

**原因**：团队新增 Go 编码需求；Java 的类层次、接口与异常规则不能直接套用。

**决策**：新增 go-coding-standards，语言特性独立按需加载；业务架构扩展既有 DDD-lite，允许消费方定义小接口，按复杂度拆包，不新增平行架构 Skill、Hook 或 DI 依赖。

**影响**：Skill 总数 22，插件 3.5.0；明确验证工具与 Go Hook 覆盖边界，同步 Claude/Codex 入口和 skill-flow。
