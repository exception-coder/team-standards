# 文档按阅读任务分层

DataFlow 连续改稿暴露出规则冲突：统一入口要求简明，过会规则却逐块叠加原型、字段表、对象图、表模型与流程；旧模板还默认生成变更记录和逐模块章节。最终材料虽然完整，参会者却难以快速找到设计重点。

本次将共用准则集中到 markdown-writing-standards：过会和概设先讲结论与图，详设承接完整契约，Quickstart 给使用方最小代码和可见结果。基础先行、扩展按触发场景展开。过会视图按本次决策需要选择，不按固定图表清单铺陈；关键条件、权限、失败恢复及真实状态仍须保留。

旧技术模板改为指向专项概设/详设，保留引用路径；业务和轻量模板去掉无用途的记录与数量阈值。新增过会与 Quickstart 可裁剪模板。已有八章/九项设计绑定继续有效，没有修改检查器、Forge 协作合同或权限规则。

图文密度参考 Assertion–Evidence、Mayer 多媒体学习研究、Diátaxis 与 C4；来源和适用边界统一保存在写作入口。模板与结构检查只能证明资源可用，实际可读性仍需审读和渲染，不能据此声称团队会议效果已验证。
