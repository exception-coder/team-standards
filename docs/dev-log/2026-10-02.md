# 2026-10-02

## 无关外部链接不阻断兼容治理

原检查器先对所有未忽略的未跟踪文件做真实路径检查，再判断任务范围。项目临时依赖目录经 Junction 指向仓库外时，即使与任务无关，也会让绑定失败。现将 Git 已跟踪改动与未跟踪候选分层：前者保持严格路径拒绝；后者如经外部链接访问，返回非阻断的 `ENVIRONMENT_PATH` 提示。任务、设计、规格和验证显式输入仍执行原有安全检查；实际参与构建的依赖应在验证记录中声明。此调整不声称能自动识别所有隐式构建依赖。

## 大量未跟踪文件不进入任务基线

后续实测发现，4.10.3 虽跳过了越界 Junction，仍会给其它未跟踪文件建立指纹；约 29,389 个临时产物触发 1,000 文件上限。现在仅对明确的任务路径及设计候选检查未跟踪文件；已跟踪、已暂存变更仍完整检查。显式输入和原有脏文件归属继续受保护，未声明且未暂存的新增文件不会被视为本次交付。
