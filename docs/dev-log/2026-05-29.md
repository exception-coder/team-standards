# 开发日志 · 2026-05-29

## 注释红线单一来源化:`bugfix-coding-style` 红线表整体收口到 `coding-standards-common` §5.4 + §5.4.1

**原因:** 用户在 korepos `refund_confirm_service.dart` 上发现 AI 反复违规注释规则——私有方法 `_validateMethodsAmountSum` 上方写 12 行 dartdoc 讲"前端契约 / 早期版本曾要求 / 现已统一"的契约迁移史;`if (cancelBridgeServiceFeeAmount != null)` 上方堆 5 行行内 WHY 讲"另一分支怎么走 / 联台 scaleRatio / 不走本分支不受影响";section divider `// ===== [ADDED 2026-04-28] xxx =====` 风格分节标题带日期。用户原话:"代码内部不需要一堆废话注释 / 一堆分化注释主要说明函数能力和参数就行 / 每次改两个地方不友好吧"。

根因有两层:(1) AI 训练数据里学过的"代码注释包含变更历史 / 契约演变叙事"模式没有被 skill 显式列出字面反例,只有抽象规则。(2) `coding-standards-common` §5 和 `bugfix-coding-style` 红线表 99% 重叠却各写一份,新增反例要双地维护,容易漂移和遗漏。

**改动:**
- `coding-standards-common/SKILL.md` §5 顶部新增 **§5.0.0「写注释前 3 秒自检」执行配方**(4 问:可见性 / 行数 / 历史 / 场景),让 AI 动手前先过一遍
- §5.4 重写为「注释红线全语言、全场景单一来源」,显式声明 bug 修复 / 联调 / 删冗余 / 重构 / 新功能全适用,bugfix-coding-style 不再重复定义
- §5.4 列项追加:section divider 禁令 / 私有方法多段 dartdoc 禁令 / 行内 WHY 超 1 行禁令 / 变更日志列项扩字补"内部流水号引用 + `[REWRITTEN]` + `[MODIFIED]` + Issue 号 + Ticket 号" / TODO 列项扩字补"带个人或日期"
- **新增 §5.4.1 字面反例与原因对照表**(12 条),把抽象规则落到 AI 看得见的具体字符串字面(`// [BUGFIX 2026-04-30] xxx` / `// PR #1234` / `// TODO(zhangkai 2026-04): xxx` / `// ===== [ADDED 日期] xxx =====` / "私有方法 12 行 dartdoc" / "行内 5 行 WHY" 等)
- `bugfix-coding-style/SKILL.md` 红线表整体删除,替换为指向 common §5.4 + §5.4.1 的引用指针;frontmatter description 同步反映"不再独立定义注释红线"
- bugfix-coding-style 保留独有应用层内容:v1.17 方向反转的历史背景表、推荐写法 dart 代码示例、摆放位置示例、适用范围矩阵、遇到存量 `[DEPRECATED]` / `[ADDED]` 顺手清理的边界、红色警告对照表
- `docs/anti-pattern-case-library.md` A5「注释里堆变更日志」追加 2 个 2026-05-29 refund_confirm_service 真实案例:私有方法 dartdoc 堆 12 行契约史 + 行内 5 行 WHY 旁路场景叙事
- `CLAUDE.md` 索引行 bugfix-coding-style 重写为"应用层指南"定位;coding-standards-common 关键词追加 §5.0.0 / §5.4 / §5.4.1 / 4 类新红线 7 个关键词;冲突解决规则 `bugfix-coding-style vs coding-standards-common` 行更新为"单一来源化到 common,bugfix 只承担应用层指引"

**影响:**
- 新增注释反模式只需改 `coding-standards-common` §5.4 + §5.4.1 一处,bugfix-coding-style 无需再同步维护;双地漂移风险消除
- 触发顺序里 common(§11)早于 bugfix(§10)必走,触发链路保持不变,AI 读到红线的时机不变
- AI 字面反例命中率提升:§5.4.1 把 12 条具体字符串列出来,比抽象规则更能切中 AI 训练偏好;遇到 `// ===== [ADDED 日期]` / 私有方法多段 dartdoc / 行内 5 行 WHY 时直接对照字面回避
- 不向后破坏:存量 [DEPRECATED] / [ADDED] 注释清理边界仍归 bugfix-coding-style「遇到旧标记怎么办」节,bug 修复期触发本 skill 时该指引仍可读到
